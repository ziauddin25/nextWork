Challenge

Create a products dataset with:

id
name
price
category
stock

Then solve:

1. Get all product names
2. Get products above 1000
3. Find a product by ID
4. Calculate total price
5. Find the cheapest product
6. Find the most expensive product
7. Sort products: low → high
8. Sort products: high → low
9. Check product stock
10. Filter products by category
Rules
❌ Don't use for loop where an array method is appropriate
❌ Don't copy solutions
✅ Understand the problem first
✅ Choose the appropriate array method yourself

Learn to identify which array operation a problem requires before writing the code.
